Source on GitHub; not in Maven yet.

### What principles I adhere to | Каких принципов придерживаюсь

<details>
<summary><b>English</b></summary>

- **Constructive paranoia.** I assume someone will try to break the system, it will fail at the worst moment, and people (me included) will forget details AND click the wrong thing (several times in a row).
- **Documentation:** decisions, API contracts, setup — in Markdown, with ADRs and diagrams in draw.io/Excalidraw or Mermaid, so I can put a project aside, return to it, or hand it over.
- **Research.** I research using my own methodology, with or without agents. Parallel Search, Exa, Perplexity; my skills and rules for Kilo Code/OpenCode. I save sources and findings for a knowledge base and RAG; I use vector DBs.

</details>

<details>
<summary><b>Русский</b></summary>

- **Конструктивная паранойя.** Исхожу из того, что кто-то попытается сломать систему, она упадёт в худший момент, а люди (я в том числе) забудут детали И нажмут не туда (несколько раз подряд).
- **Документация:** решения, API-контракты, настройка — в Markdown, с ADR и диаграммами в draw.io/Excalidraw или Mermaid, чтобы отложить проект, вернуться к нему или передать его.
- **Провожу исследование по своей методологии.** С агентами и без. Parallel Search, Exa, Perplexity; свои скиллы и правила для Kilo Code/OpenCode. Сохраняю источники и выводы для базы знаний и RAG; использую векторные БД.

</details>
