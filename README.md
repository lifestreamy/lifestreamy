I use AI agents to speed up work, TDD to check the results, and a personal harness built on Kilo/OpenCode. I always follow my own Deep Research methodology and build knowledge bases. And I design them to be extensible: adding something new stays cheap and never breaks what already works.**

I know what it takes to get a system from idea to production. Requirements, system design, specs, architecture, API design, basic infosec. I judge the task size first, then pick technologies for it. I pick the infrastructure provider, set up DNS, SSL and networks where needed. I build the backend and frontend where needed, deploy with CI/CD and Infrastructure as Code — Ansible, Python, bash, PowerShell. I set up backups.

I talk to real people: I translate between business and technical language both ways, and explain complex things simply. I ALWAYS write documentation (if you cannot find some of mine anywhere — either it is not public, or I had not reached enlightenment back then). The goal: I do not have to stuff my head, nuances are easy to recall, and good documentation is easy to feed to agents for effective work. And clients understand what works and how. No bus factor.
